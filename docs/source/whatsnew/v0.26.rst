Version 0.26 (September 16, 2026)
=================================

The documentation is now hosted on Read The Docs at the following URL:
https://cartopy.readthedocs.io/stable/

This release also includes a fix for compatibility with PROJ 9.8, several
robustness fixes for gridline labels and polygon transforms, and a more
reliable download location for GSHHS coastline data.

Minimum supported versions of dependencies

* Python 3.11
* Matplotlib 3.8
* Numpy 1.26
* Pyproj 3.6


🎉 Features
-----------

* Ruth Comer added the ``autolim`` keyword to the `.add_geometries` and `.add_feature`
  methods so that axes extents can get automatically updated when adding new features
  to an axes. (:pull:`2569`)

* Thomas Guymer added ThunderForest tiles as another image tile provider. (:pull:`2575`)

* Thomas Guymer exposed the ``regrid_shape`` and ``interpolation`` keyword arguments on
  `.background_img`, so high-resolution background images are no longer forced to be
  downsampled to 750 pixels. (:pull:`2609`)

* Do Ngoc Khanh exposed the ``gamma`` parameter of the Oblique Mercator projection. (:pull:`2627`)

* Greg Lucas vectorized the coordinate extraction in `.shapely_to_path`,
  giving a 50-100x speedup for geometries with many points. (:pull:`2693`)

* Image tile downloaders now auto-detect whether each tile is RGB or RGBA from its
  image data instead of assuming a fixed format, thanks to Greg Lucas. (:pull:`2738`)

* Elliott Sales de Andrade enabled building and testing free-threaded wheels and
  wheels for Python 3.15. (:pull:`2720`)


🐛 Bug Fixes
------------

* Greg Lucas fixed an issue with small anti-meridian crossing polygons during projection. (:pull:`2594`)

* Thomas Guymer fixed an issue with potential cache name clashes based on different styles. (:pull:`2603`)

* Raphael Quast fixed a bug with polygons that had no paths to return an empty path
  rather than raising an error. (:pull:`2619`)

* Greg Lucas fixed an issue when projecting a geometry with an empty point. (:pull:`2640`)

* Elliott Sales de Andrade fixed hard-coded limits and thresholds that produced
  incorrect projections when a projection's Globe had a non-default radius. (:pull:`1607`)

* Guillermo N. Leiro Arroyo fixed gridline labels on curved projection boundaries (e.g.
  Robinson) ignoring `.right_labels`/`.left_labels` visibility settings. (:pull:`2649`)

* Guillermo N. Leiro Arroyo fixed shared `.GeoAxes` (via ``sharex``/``sharey``) not propagating
  interactive zoom to sibling subplots after features were added. (:pull:`2652`)

* Ryan May fixed compatibility with PROJ 9.8, which changed how the equidistant
  cylindrical projection handles ellipsoids and broke the assumptions `.PlateCarree`
  relied on; the temporary upper pin on PROJ has been removed. (:pull:`2642`, :pull:`2653`)

* Greg Lucas replaced the ring orientation check with a more robust shoelace-formula
  calculation that handles self-intersecting rings correctly. (:pull:`2665`)

* Ruth Comer fixed the gridliner title adjustment logic incorrectly accounting for
  invisible labels. (:pull:`2667`)

* Guillermo N. Leiro Arroyo fixed gridline labels being hidden by false-positive overlap
  detection at a rotation of 90 degrees. (:pull:`2668`)

* Greg Lucas fixed a memory leak where the wrapped collection of a ``GeoQuadMesh`` was not
  removed along with the mesh itself. (:pull:`2676`)

* Katelyn FitzGerald updated `.LatitudeLocator` to follow an upstream Matplotlib change
  that made `matplotlib.ticker.MaxNLocator` keywords explicit. (:pull:`2690`)

* Greg Lucas fixed `.path_to_shapely` misclassifying closed triangle paths as line
  strings instead of polygons. (:pull:`2692`)

* Ruth Comer skipped title positioning calculations entirely when an axes has no
  titles set. (:pull:`2702`)

* David Vadnais fixed deepcopy/pickling of CRS subclasses created from WKT. (:pull:`2727`)

* Ruth Comer fixed transforms of filled paths by using the shoelace formula to
  determine input polygon orientation. (:pull:`2741`)
